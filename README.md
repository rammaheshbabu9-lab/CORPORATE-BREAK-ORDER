# ONE MILLION PIXELS INDIA 🇮🇳

One Million Pixels India is a digital advertising and
business visibility platform where companies can own
a digital pixel space and create their brand profile.

## Features

- One Million Pixel concept
- Company logo display
- Company profile
- Website link
- Pixel booking
- Zone based pricing
- Payment integration
- Booking confirmation
- Search companies
- Responsive UI
